# Security Policy

## Supported versions

Security fixes go into the latest release only.

## Reporting a vulnerability

Do not open a public issue. Report privately through GitHub:
https://github.com/byrodi/wynncard/security/advisories/new

Include the affected version, steps to reproduce and the impact you expect. Reports are acknowledged within 7 days. A confirmed vulnerability is fixed in a new release and disclosed through a GitHub Security Advisory, normally within 90 days of the report.
